# 元素领域 Ez Element 页面原型

打开 index.html 即可使用；无需安装依赖。品牌名及所有数据均为虚构示例。

三个角色工作台可切换，覆盖学员首页、私教与团课预约、预约记录、课包流水、消息；教练工作台、名单结课、可约时间；管理总览、团课发布/停课、人员审核、线下购课入账和 CSV 导出。

建议体验：学员端约课 → 预约核心力量 → 教练端确认到课 → 学员端课包查看流水 → 管理端登记购课 → 学员端核对余额。

数据保存在当前浏览器 localStorage。左侧“重置演示数据”恢复初始状态。原型日期固定为 2026-10-27，周排班与学员选日期覆盖 10 月 28 日至 11 月 3 日。

范围：前端交互原型，不是微信小程序安装包，没有服务端、真实鉴权、微信订阅消息或收款能力。角色切换仅用于体验。课时与名额变动是浏览器模拟，不具备生产并发保证。

明确简化：取消均按免费处理；允许提前结课；教练私教时段按七天独立保存，支持复制到其他日期与当天停止新预约；通知是共用事件列表；其他初始学员仅作为名额背景；可交互账户为陈晓。正式版需要落实方案中的时间规则、账号权限、课包适用性、服务端事务和可靠通知。
