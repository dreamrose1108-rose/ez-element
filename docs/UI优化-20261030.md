## 信息分层第二轮

- 学员首页默认最近三条未结算预约，未来课程优先；过去已结束但未结算的课程明确标为待确认出勤。完成（含爽约）与取消分别筛选，查看更多每次增加十条，仅针对当前服务端已加载记录。
- 预约压缩为课程状态、时间、人员金额摘要；详情展开后提供取消操作和价格明细。教练确认到课、标记爽约仍直接展示。
- 教练待办优先待确认，提供待确认、今日、待办、完成、取消筛选。
- 管理首页仅保留经营摘要、待审核入口和最近三条消息，历史消息可展开。教练工资与授课历史移至收款账务的教练明细栏目。
- 收款账务分为登记收款、账户流水、教练明细。充值只展示当前价格，通过学员详情维护价格；现有充值接口仍要求两种课程价格，未设置时明确引导先保存。刷新数据后重新读取当前学员价格。

采用 ui-adviser 的任务优先方向，延续黄灰品牌与固定底部导航。服务学员快速预约、教练处理授课、管理人员查经营与维护会员。

设计规则：黄色用于主操作、日期选中与课程时间标记；白色承载内容；灰色用于辅助信息。首页按问候、主操作、数据摘要、业务记录排序。底部导航保留各角色已有分类，顶部仅作身份切换。

本轮落实：移除学员首页宣传横幅，余额卡压缩为浅色摘要；订阅提醒移至预约记录之后；课程卡同一行呈现起止时间；日期选中增加深色边框；教练指标增加分隔；底部选中项增加定位短线。
